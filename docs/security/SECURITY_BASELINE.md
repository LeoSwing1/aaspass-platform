# AasPass Security Baseline

- HTTPS everywhere
- API-layer RBAC
- Secure token/session handling
- Rate limiting and OTP abuse protection
- Encryption in transit/at rest
- Secrets outside source control
- Signed payment webhook verification
- Idempotency for payment/order mutations
- Input validation and output encoding
- SQL injection protection through parameterized queries/ORM
- XSS/CSRF controls where applicable
- Secure file/KYC upload handling
- Audit logs for admin/finance actions
- Device/account anomaly hooks
- Location privacy controls
- Data retention and deletion policy
- Backup and disaster recovery
