# Block 13 Final — Cross-App UI/UX Betterment

This release is UI/UX-only.

Customer, Vendor and Delivery Partner are Flutter mobile applications.
Support and AasPass HQ/Admin are web applications.

The legacy vendor web application has been removed from the production tree; the canonical vendor surface is `apps/vendor`.

## Visual goals
- AasPass-specific green/mint visual language.
- Grocery-commerce hierarchy inspired by familiar best practices without copying another brand.
- Strong imagery, banners, product rails, store cards and compact operational cards.
- Responsive spacing and overflow-safe layouts.
- 48dp minimum primary control targets.
- Reduced-motion friendly animation durations.
