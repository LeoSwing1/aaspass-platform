# AasPass Module Map

## /customer
Customer-facing commerce experience: onboarding, auth, location, discovery, categories, vendors, products, cart, checkout, orders, tracking, notifications, profile, support and referrals.

## /vendor
Merchant experience: onboarding/KYC, subscription, store profile, catalog, inventory, order queue, preparation, staff, analytics, settlements and promotions.

## /delivery-partner
Delivery experience: onboarding/KYC, availability, assignment, route, pickup, proof of delivery, earnings, wallet, payouts and support.

## /support
Agent/lead console: ticket queue, customer/vendor/delivery context, SLA, internal notes, refund request workflow, escalation and audit trail.

## /admin
AasPass HQ: people, vendors, customers, delivery, orders, zones, pricing, subscriptions, finance, settlements, campaigns, support, configuration, integrations, security and analytics.

## /backend
Shared source of truth for identity, RBAC, locality/serviceability, catalog, order management, payment sessions, ledger, delivery orchestration, notifications, support and audit.
