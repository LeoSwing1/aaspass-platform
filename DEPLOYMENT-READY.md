# AasPass deployment-ready build

This source package includes Android platform projects for Customer, Vendor and Delivery, production application IDs, network/location permissions, and a clean source tree without generated build output or local Git metadata.

## Web apps
- `apps/admin` — Next.js Admin HQ
- `apps/vendor` — Next.js Vendor web plus Flutter Vendor mobile
- `apps/support` — Support web scaffold

## Flutter apps
- `apps/customer` — Customer
- `apps/vendor` — Vendor
- `apps/delivery-partner` — Delivery

Before production mobile release, configure release signing and production authentication.
