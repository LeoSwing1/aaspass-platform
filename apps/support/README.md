# AasPass Support Console

Web-based support console for AasPass operations. This is intentionally a browser application, not a customer mobile app.

## Scope
- Customer, vendor and delivery tickets
- Order-linked investigations
- SLA/priority/status workflows
- Public replies and internal notes
- Escalation and audit trail
- Role-scoped support access

The console shares the AasPass backend and authentication/RBAC model with the other platform surfaces.
