# AasPass Backend

Shared backend for every AasPass application.

Recommended modules:
- auth
- rbac
- users
- vendors
- vendor-plans
- catalog
- inventory
- locality
- serviceability
- cart
- orders
- payments
- ledger
- settlements
- delivery
- notifications
- support
- analytics
- audit

The backend is authoritative for pricing, order state, permissions and financial records.
